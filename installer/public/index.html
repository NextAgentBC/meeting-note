第一次听说 Cloudflare？没关系

你不需要懂服务器。

Cloudflare 是什么？

它是 Meeting Note 运行的云平台。你只需免费注册并授权，安装器会自动完成技术设置。

只有手机也能安装吗？

可以。注册、授权、安装和 Face ID 认领都能在手机浏览器完成。完成后可把 PWA 添加到主屏幕，像 App 一样使用。

安装器能看到我的会议和笔记吗？

不能。安装器只创建资源，不读取你的会议、录音或笔记；这些内容保存在你自己的 Cloudflare 账户。

以后可以停止使用或删除吗？

可以。你可以随时在自己的 Cloudflare 账户中删除应用及数据，不需要联系我们。
